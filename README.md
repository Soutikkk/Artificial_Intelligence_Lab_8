# 📊 Time Series Analysis and Forecasting

A collection of Python programs focused on **Time Series Analysis, Statistical Modeling, and Machine Learning-Based Forecasting**. This repository covers essential techniques for analyzing time-dependent data, identifying patterns, preprocessing datasets, and building forecasting models.

## 📌 Programs Included

| No. | Program                                              | Description                                                                                         |
| --- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 1   | **Creating, Indexing and Visualizing a Time Series** | Creating time series data, setting date-time indexes, and visualizing trends using plots.           |
| 2   | **Time Series Preprocessing**                        | Data preprocessing, handling missing values, and applying smoothing techniques.                     |
| 3   | **Moving Average and Exponential Smoothing**         | Implementing moving averages and exponential smoothing for forecasting.                             |
| 4   | **Autocorrelation and Lag Feature Analysis**         | Analyzing autocorrelation and creating lag features to identify relationships between observations. |
| 5   | **Decomposition and Stationarity Analysis**          | Decomposing time series into trend, seasonal, and residual components and examining stationarity.   |
| 6   | **ARIMA-Based Time Series Forecasting**              | Building ARIMA models for statistical time series forecasting.                                      |
| 7   | **Machine Learning Forecasting Using Lag Features**  | Applying machine learning techniques with lag features to predict future values.                    |
| 8   | **Model Evaluation and Multi-Step Forecasting**      | Evaluating forecasting models and implementing multi-step predictions.                              |

## 🎯 Objectives

* Understand the fundamentals of time series data.
* Learn to create, index, preprocess, and visualize time series datasets.
* Identify trends, seasonality, and patterns in time-dependent data.
* Analyze autocorrelation and use lag features.
* Understand stationarity and time series decomposition.
* Implement statistical forecasting models such as ARIMA.
* Apply machine learning techniques to time series forecasting.
* Evaluate model performance and perform multi-step forecasting.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Libraries:**

  * `NumPy` – Numerical computations
  * `Pandas` – Data manipulation and time series handling
  * `Matplotlib` – Data visualization
  * `Seaborn` – Statistical data visualization
  * `Statsmodels` – Statistical analysis, decomposition, and ARIMA
  * `Scikit-learn` – Machine learning and model evaluation

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd <YOUR_REPOSITORY_NAME>
```

### 3. Install Required Libraries

```bash
pip install numpy pandas matplotlib seaborn statsmodels scikit-learn
```

### 4. Run a Program

```bash
python "ARIMA-Based Time Series Forecasting.py"
```

Replace the filename with the Python program you want to execute.

* 📉 **Financial Analysis:** Stock market trends and price forecasting.
